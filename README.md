# Desenvolvimento Web

### Este repositório reúne todas as atividades, projetos e estudos desenvolvidos ao longo das disciplinas de Desenvolvimento Web I, II e III. Os conteúdos estão organizados por período letivo, pois algumas disciplinas foram cursadas em anos diferentes e com professores distintos. Ao longo desses períodos, são abordados conteúdos que vão desde a construção de páginas com HTML e CSS até o desenvolvimento de aplicações completas utilizando Vue.js e Django.
